Docker والتكامل المستمر

أصبح Docker عنصراً لا غنى عنه في خطوط CI/CD الحديثة، إذ يضمن الاتساق بين بيئات الاختبار والإنتاج.

خط GitHub Actions باستخدام Docker

name: CI/CD Pipeline
on:
  push:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Build test image
        run: docker build --target test -t app:test .
      - name: Run tests
        run: docker run app:test php bin/phpunit

  build-and-push:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Build production image
        run: docker build --target production -t app:latest .
      - name: Push to registry
        run: |
          echo "$REGISTRY_TOKEN" | docker login -u user --password-stdin
          docker push app:latest

تحسين الـ cache

يُعدّ cache طبقات Docker عاملاً حاسماً في سرعة خط الـ pipeline:

- name: Set up Docker Buildx
  uses: docker/setup-buildx-action@v3
- name: Build with cache
  uses: docker/build-push-action@v5
  with:
    cache-from: type=gha
    cache-to: type=gha,mode=max

تشغيل الاختبارات بالتوازي

  • استخدم Docker Compose لتشغيل خدمات الاختبار (قاعدة البيانات، Redis)
  • وزّع مجموعات الاختبارات على حاويات (containers) منفصلة لتعمل بالتوازي
  • نظّف الموارد بعد كل تنفيذ

تتيح هذه الاستراتيجية تقليص زمن النشر من 30 دقيقة إلى أقل من 5 دقائق.
