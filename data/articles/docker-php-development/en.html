The same dev environment for the whole team

No more "it works on my machine". Docker guarantees that every developer works in an identical environment, eliminating compatibility issues.

A complete development stack

version: '3.8'
services:
  php:
    build:
      context: .
      dockerfile: Dockerfile.dev
    volumes:
      - .:/var/www/html
      - composer-cache:/root/.composer
    environment:
      - APP_ENV=dev
      - XDEBUG_MODE=debug

  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: app
    ports:
      - "3306:3306"
    volumes:
      - mysql-data:/var/lib/mysql

  mailhog:
    image: mailhog/mailhog
    ports:
      - "8025:8025"

volumes:
  composer-cache:
  mysql-data:

Xdebug configuration

Debugging is essential during development. Here is the optimal Xdebug configuration:

[xdebug]
xdebug.mode=debug
xdebug.start_with_request=yes
xdebug.client_host=host.docker.internal
xdebug.client_port=9003

Hot reload and performance

On macOS and Windows, mounted volumes can be slow. Use synchronization strategies:

  • Mutagen for fast file synchronization
  • Exclude vendor/ and node_modules/ from the mount
  • Use named volumes for dependencies

With this approach, any new developer joining the team has a working development environment in under 5 minutes.
