GraphQL: بديل قوي لـ REST

يتيح GraphQL للعملاء طلب البيانات التي يحتاجونها بالضبط. في مشاريع مثل مشاريع Matalto وManymore، ساعدت هذه المرونة على تقليل عدد طلبات API بشكل كبير.

التثبيت مع Symfony

composer require overblog/graphql-bundle
composer require overblog/graphiql-bundle --dev

تعريف المخطط (schema)

# config/graphql/types/Product.types.yaml
Product:
    type: object
    config:
        fields:
            id:
                type: "ID!"
            name:
                type: "String!"
            price:
                type: "Float!"
            category:
                type: "Category"
                resolve: "@=resolver('product_category', [value])"

Resolver

class ProductResolver implements ResolverInterface
{
    public function __construct(
        private ProductRepository $repository,
    ) {}

    public function resolve(Argument $args): array
    {
        if (isset($args['id'])) {
            return $this->repository->find($args['id']);
        }
        return $this->repository->findAll();
    }
}

class ProductCategoryResolver implements ResolverInterface
{
    public function resolve(Product $product): Category
    {
        return $product->getCategory();
    }
}

استعلام GraphQL

query {
  products(first: 10) {
    id
    name
    price
    category {
      name
    }
  }
}

المزايا مقارنةً بـ REST

  • لا جلب زائد (over-fetching): العميل يختار الحقول
  • لا جلب ناقص (under-fetching): طلب واحد للبيانات المترابطة
  • أنواع صارمة: مخطط يوثّق نفسه بنفسه
  • تطوّر سهل: إضافة حقول دون كسر العملاء الحاليين
