مراقبة أداء النظام

المراقبة (monitoring) الجيدة ضرورية لاكتشاف المشكلات قبل أن تؤثر في المستخدمين.

أدوات أساسية

# Real-time CPU and memory
htop

# Disk statistics
iostat -x 1

# Network traffic
iftop -i eth0

# Resource-hungry processes
ps aux --sort=-%mem | head -20

المراقبة باستخدام Prometheus وNode Exporter

# Install Node Exporter
wget https://github.com/prometheus/node_exporter/releases/download/v1.7.0/node_exporter-1.7.0.linux-amd64.tar.gz
tar xvfz node_exporter-*.tar.gz
sudo mv node_exporter-*/node_exporter /usr/local/bin/

تنبيهات النظام

اضبط تنبيهات للمقاييس الحرجة:

  • CPU: تنبيه عند تجاوز 80% لمدة 5 دقائق
  • الذاكرة: تنبيه عند تجاوز 90%
  • القرص: تنبيه عند تجاوز 85%
  • Load average: تنبيه عند تجاوز عدد وحدات المعالجة (CPUs)

سكربتات مراقبة مخصّصة

#!/bin/bash
# check_resources.sh
CPU=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}')
MEM=$(free -m | awk 'NR==2{printf "%.1f", $3*100/$2}')
DISK=$(df -h / | awk 'NR==2{print $5}' | tr -d '%')

echo "CPU: ${CPU}% | MEM: ${MEM}% | DISK: ${DISK}%"

if (( $(echo "$CPU > 80" | bc -l) )); then
  echo "ALERT: high CPU!" | mail -s "Server alert" admin@example.com
fi
