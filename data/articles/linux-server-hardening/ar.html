تأمين خادم Linux الخاص بك

تأمين خادم Linux هو الخطوة الأولى قبل أي نشر في بيئة الإنتاج. إليك الإجراءات الأساسية.

إعداد SSH

# /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
Port 2222
MaxAuthTries 3
AllowUsers deploy

جدار الحماية مع UFW

sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 2222/tcp    # SSH
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS
sudo ufw enable

التحديثات التلقائية

sudo apt install unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades

Fail2Ban

احمِ خادمك من هجمات القوة الغاشمة (brute force):

sudo apt install fail2ban
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local

قائمة التحقق الأمنية

  • تعطيل تسجيل دخول root عبر SSH
  • الاعتماد حصرياً على المصادقة بالمفاتيح
  • إعداد جدار حماية صارم
  • تثبيت Fail2Ban وإعداده
  • تفعيل التحديثات الأمنية التلقائية
  • إعداد سجلات (logs) مركزية
  • إنشاء نظام لمراقبة الخادم (monitoring)
