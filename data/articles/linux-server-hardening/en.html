Securing your Linux server

Securing a Linux server is the very first step before any production deployment. Here are the essential measures.

SSH configuration

# /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
Port 2222
MaxAuthTries 3
AllowUsers deploy

Firewall with UFW

sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 2222/tcp    # SSH
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS
sudo ufw enable

Automatic updates

sudo apt install unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades

Fail2Ban

Protect yourself against brute-force attacks:

sudo apt install fail2ban
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local

Security checklist

  • Disable root login over SSH
  • Use key-based authentication only
  • Configure a restrictive firewall
  • Install and configure Fail2Ban
  • Enable automatic security updates
  • Set up centralized logging
  • Put system monitoring in place
