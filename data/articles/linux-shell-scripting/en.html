The art of shell scripting

Shell scripting remains a fundamental tool for any DevOps engineer. Here are the essential patterns and best practices.

Structure of a robust script

#!/bin/bash
set -euo pipefail
IFS=$'\n\t'

# Variables
readonly SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
readonly LOG_FILE="/var/log/deploy.log"

# Functions
log() {
    echo "[$(date +'%Y-%m-%d %H:%M:%S')] $*" | tee -a "$LOG_FILE"
}

cleanup() {
    log "Cleaning up..."
    rm -rf "$TEMP_DIR"
}
trap cleanup EXIT

# Main script
main() {
    log "Starting deployment"
    # ...
    log "Deployment complete"
}

main "$@"

Useful patterns

# Check whether a service is active
check_service() {
    if systemctl is-active --quiet "$1"; then
        echo "$1 is active"
    else
        echo "$1 is inactive" && return 1
    fi
}

# Retry with backoff
retry() {
    local max_attempts=$1; shift
    local attempt=1
    while [ $attempt -le $max_attempts ]; do
        if "$@"; then return 0; fi
        echo "Attempt $attempt/$max_attempts failed"
        sleep $((attempt * 2))
        ((attempt++))
    done
    return 1
}

Best practices

  • Always use set -euo pipefail
  • Document variables and functions
  • Use functions for readability
  • Handle errors with trap
  • Test with shellcheck
