إدارة تطبيقاتك باستخدام systemd

systemd هو مدير الخدمات القياسي في Linux. يتيح لك إنشاء خدمة مخصصة إدارة دورة حياة تطبيقاتك.

إنشاء خدمة

# /etc/systemd/system/myapp.service
[Unit]
Description=My PHP Application
After=network.target mysql.service
Requires=mysql.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/var/www/myapp
ExecStart=/usr/bin/php bin/console messenger:consume async --limit=100
ExecReload=/bin/kill -HUP $MAINPID
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target

الأوامر الأساسية

sudo systemctl daemon-reload
sudo systemctl enable myapp
sudo systemctl start myapp
sudo systemctl status myapp
journalctl -u myapp -f

إدارة workers الخاصة بـ Symfony Messenger

بالنسبة لتطبيقات Symfony التي تستخدم Messenger، أنشئ خدمة متعددة النُّسخ (instances):

# /etc/systemd/system/messenger-worker@.service
[Service]
ExecStart=/usr/bin/php /var/www/app/bin/console messenger:consume async --time-limit=3600
Restart=always

# Start 3 workers
sudo systemctl enable messenger-worker@{1..3}
sudo systemctl start messenger-worker@{1..3}

أفضل الممارسات

  • حدّد الاعتماديات باستخدام After وRequires
  • اضبط Restart=always لضمان المرونة وقدرة الخدمة على التعافي
  • استخدم سجلات systemd (journal) بدلاً من ملفات السجل
  • قيّد الموارد باستخدام cgroups
