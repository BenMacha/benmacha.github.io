تحسين أداء PHP لبيئة الإنتاج

أداء PHP عامل حاسم في التطبيقات ذات الحركة العالية. في CCM Benchmark، حيث تستقبل المواقع ملايين الزوار يومياً، كل جزء من الألف من الثانية له أهميته.

OPcache: الأساس

; php.ini - Optimal OPcache configuration
opcache.enable=1
opcache.memory_consumption=256
opcache.max_accelerated_files=20000
opcache.validate_timestamps=0
opcache.save_comments=1
opcache.preload=/var/www/app/config/preload.php
opcache.preload_user=www-data

التحميل المسبق (Preloading) في PHP 8

// config/preload.php
require dirname(__DIR__).'/vendor/autoload.php';

// Preload frequently used classes
$files = glob(dirname(__DIR__).'/src/Entity/*.php');
foreach ($files as $file) {
    opcache_compile_file($file);
}

التحليل (Profiling) باستخدام Blackfire

# Install the Blackfire agent
curl -s https://packagecloud.io/install/repositories/blackfire/agent/script.deb.sh | sudo bash
sudo apt install blackfire-agent

# Profile a request
blackfire curl http://localhost/api/products

تحسينات Doctrine

  • تفعيل التخزين المؤقت (cache) للاستعلامات والنتائج
  • استخدام استعلامات DQL مع اختيار جزئي للحقول
  • تجنّب التحميل الكسول (lazy loading) باستخدام عمليات ربط (joins) صريحة
  • إعداد التخزين المؤقت من المستوى الثاني (second-level cache)
// Doctrine query cache
$query = $em->createQuery('SELECT p FROM App\Entity\Product p')
    ->enableResultCache(3600, 'products_list');

$results = $query->getResult();
