API Platform: إطار عمل الـ API لـ Symfony

يُعدّ API Platform الإطار المرجعي لبناء واجهات API حديثة باستخدام Symfony، إذ يولّد تلقائياً واجهة REST وGraphQL انطلاقاً من الكيانات (entities) الخاصة بك.

التثبيت والإعداد

composer require api
# Automatically creates the API Platform configuration

إنشاء مورد API

use ApiPlatform\Metadata\ApiResource;
use ApiPlatform\Metadata\Get;
use ApiPlatform\Metadata\GetCollection;
use ApiPlatform\Metadata\Post;

#[ApiResource(
    operations: [
        new GetCollection(),
        new Get(),
        new Post(security: "is_granted('ROLE_ADMIN')"),
    ],
    paginationItemsPerPage: 20,
)]
#[ORM\Entity]
class Product
{
    #[ORM\Id, ORM\GeneratedValue, ORM\Column]
    private ?int $id = null;

    #[ORM\Column(length: 255)]
    #[Assert\NotBlank]
    private string $name;

    #[ORM\Column(type: 'decimal', precision: 10, scale: 2)]
    private string $price;

    // Getters and setters...
}

الفلاتر والبحث

#[ApiFilter(SearchFilter::class, properties: ['name' => 'partial'])]
#[ApiFilter(RangeFilter::class, properties: ['price'])]
#[ApiFilter(OrderFilter::class, properties: ['name', 'price'])]

مجموعات التسلسل (Serialization Groups)

#[ApiResource(
    normalizationContext: ['groups' => ['product:read']],
    denormalizationContext: ['groups' => ['product:write']],
)]

المزايا

  • توثيق OpenAPI يُولَّد تلقائياً
  • دعم JSON-LD وHydra
  • ترقيم الصفحات (pagination) والفلترة والترتيب مدمجة
  • تحقق تلقائي من صحة البيانات عبر قيود (constraints) Symfony
  • دعم أصلي لـ GraphQL

تستخدم منصات مثل CCM Benchmark إطار API Platform لعرض خدماتها الداخلية عبر واجهات API موحّدة.
